# Описание
Реализована гибридная криптосистема с использованием асимметричного алгоритма **RSA** и симметричного **CAST5**. 
Сделано CLI и веб-приложение с использованием `aiohttp` и `jinja2` для генерации ключей, шифрования и расшифровки сообщений.
# Запуск
Чтобы все работало необходимо установить `requirements.txt`

`python app.py` и перейти на `http://localhost:8080` - веб приложение

```bash
python crypto.py -g -a
python crypto.py -e -a
python crypto.py -d -a
# генерация, шифрование и расшифровка с использованием настроек по умолчанию
```
Пользовательские настройки в `/config/user_settings.json`
# Файлы проекта
`app.py` - веб-приложение

`crypto.py` - CLI приложение

`/src/atomic` - код для RSA, CAST5, сериализации и гибридной криптосистемы

`/src/web` - код веб приложения

`/config` - файлы конфигурации

`/default` - путь с файлами сгенерированных ключей и шифрованных/расшифрованных файлов по умолчанию

`/static` и `/templates` - фронт для сайта
