# Лабораторная №2 "Статистический анализ псевдослучайных последовательностей"

## Отчет
Было написано консольное и веб-приложение на Flask для генерации случайных последовательностей, используя языки программирования Java и C++.

Чтобы генерировать случайные последовательности, используя Python, была использована библиотека `subproccess`, а файлы были скомпилированы в `.exe`. Причем Java файл был скомпилирован, используя Launch4j.

[VirusTotal C++ Exe](https://www.virustotal.com/gui/file/d7dd8f848298c2f8d45c14928e7063f621e122f022c3467cd1a76f4e2889d145)
[VirusTotal Java Exe](https://www.virustotal.com/gui/file/62c25b016d559b8e5a557a7f4089ec6b26bcf7b45843b0bcddc72660422c98a6)

Затем, были реализованы 3 NIST теста: частотный побитовый тест (`frequency_bit_test.py`), тест на одинаковые подряд идущие биты (`next_bit_test.py`) и тест на самую длинную последовательность единиц в блоке (`longest_run_test.py`).

Результаты также были проверены с помощью [сайта](https://mzsoltmolnar.github.io/random-bitstream-tester/) (только на нем "3. Runs Test" реализован немного неправильно).

## Результаты
Запускаем программу `python test.py cpp` и получаем:
```
01010110010111011011001001111000010100111101001101101110111000010001110001010101101110010100110111100000110010110011000111011011
```

Частотный побитовый тест: `0.4795001221869535`
Тест на самую длинную последовательность единиц в блоке: `0.1524750467547308`
Тест на одинаковые подряд идущие биты: `0.26734947307149204`

Так как все результаты `>= 0.01`, то тесты пройдены.

---

Для Java: `python test.py java`:
```
01001111000001010111010100010001001000100100001000000001011010101110010100100000001011001000100001111001000100111010000101100011
```

Частотный побитовый тест: `0.008009942329880044`
Тест на самую длинную последовательность единиц в блоке: `0.05116734662089044`
Тест на одинаковые подряд идущие биты: `0.3022092394495788`

Видим, что частотный побитовый тест последовательность не прошла, так как она `<= 0.01`.
В этом тесте доля единиц и нулей должна быть примерно по 0.5, а тут видно, что единиц 49 штук, а нулей 79, поэтому тест не пройден.
## Программа
### Установка
```bash
git clone <repo>
cd <dir>
pip install -r requirements.txt
```
### Запуск
Выполните `python app.py` и перейдите по данному адресу.

Чтобы использовать консольное приложение:
```bash
python test.py cpp
# выполнит все тесты над C++ последовательностью

python test.py java freq_bit, next_bit
# выполнит частотный побитовый тест и тест на одинаковые подряд идущие биты над Java последовательностью
```
### Структура проекта
`/config/` - конфигурационные файлы
`/src/` - исходные файлы
`/static/`, `/templates/` - статические и шаблонные файлы для веб-приложения
`app.py` - веб-приложение
`test.py` - консольное приложение
